# 阶段边界

**阶段（phase）** 是会话内的一块工作——访谈、实现、QA。定义刻意保持模糊：一个阶段在你想到*"好了，我们搞定那部分了"*时结束。

**阶段边界**是两个阶段之间的间隙，也是这个决策唯一该发生的地方。阶段中途没有决策要做——继续，或者把剩下的工作拆给子 agent。阶段中途压缩会让 agent 丢掉线索。

## 五个选项

| 选项 | 作用 |
| ------------ | --------------------------------------------------------------- |
| **继续（Continue）** | 留在会话中。完全没有上下文切换。 |
| **`/clear`** | 清空上下文窗口，从零开始。 |
| **`/handoff`** | 写一个可移植的 markdown 文件，在任何地方用它孕育一个会话。 |
| **子 agent（Subagent）** | 把任务送到它自己的上下文窗口，拿回一份报告。 |
| **`/compact`** | 压缩当前上下文，用摘要孕育一个新会话。 |

## 决策树

在边界处自上而下地工作。第一个**是**胜出。

**1. 你能在这个会话中继续吗？** 两件事让答案为是：下一个阶段需要这个阶段作为**一手资料**，或者你还有足够的[智能区间](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）装得下下一个阶段。访谈 → 实现是标准的"是"：实现想要逐字保留的推理，而不是它的摘要。继续零成本、零损失，所以先排除任何其他选项之前把它排除掉。

**2. 上下文与接下来要做的事无关吗？** 这个会话里的一切——探索、决策、死胡同——都是可丢弃的吗？如果是，**`/clear`**。它是棋盘上最廉价的走法：不花时间，交回整个窗口。`/clear` 也不是终局——旧会话仍然可恢复。

判断错误的代价是单向的。清掉*相关的*上下文，你就失去了所构建之物的**为什么**，而无论把 diff 读多少遍都找不回来。

**3. 你需要交接吗？** `/handoff` 很窄。只有当你：

- 切换到**新的 harness**（Claude → Codex），
- 移动到**新的目录**或仓库，
- 把工作交给**同事**，
- 或分叉一个你在**阶段中途**发现的旁路任务，且不脱离当前正在做的事。

这个列表就是全部条款。`/handoff` 买到的是**可移植性**——一份会旅行的文件。如果没有东西在旅行，你就不需要它。

**4. 任务能 AFK 完成吗？** 它是否被限定得足够紧，可以在你离开键盘、无需引导的情况下运行？如果是，把它交给**子 agent**，让这个会话保持原样。自动化审查是标准情况：agent 读 diff 并报告，它做这些时不需要你。

**5. 否则，`/compact`。** 相关上下文、同一 harness、同一目录，而且你需要留在回路中——决策树落到这里，而且经常落到这里。给它一个指令（`/compact we're going to QA this area`），让摘要保留下一个阶段需要的东西。

`/compact` 是**默认，不是第一伸手可及处**。它在底部，因为它上面的四个问题都更廉价或更精确。人们从这里开始时的失败模式，是一个对摘要压平的那个决策自信地搞错的新会话。

## 一手和二手来源

除了**继续**之外的每个动作，都把**一手来源**变成**二手来源**——发生过的会话，被它的摘要取代。权衡始终是同一种形状：

| 来源 | 信息 | 噪音 | 活动空间 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（继续） | 完整 | 多 | 小 |
| 二手（`/compact`、`/handoff`） | 有损 | 少 | 大 |

这就是问题 1 排第一的原因。只有当留下比保存更贵时，你才付出有损的代价。

## 这些都是判断

这些问题不是客观的——每个都掺着品味，同一条边界在不同日子里可以走向两个方向。价值在于**按顺序**、在边界处而不是在工作中途问它们。
