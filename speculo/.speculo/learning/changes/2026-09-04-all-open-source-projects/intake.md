# 学习 intake：Sub2API Plus 全链路学习

## 学习对象

当前阶段只学习 `open-ai-agent/sub2api-plus`。此前曾登记整个仓库的 62 个 submodule 为长期学习对象；本次由学习者明确收窄范围，其他模块暂不进入当前 change，未来可另行创建或恢复学习 change。

## 学习动机

扩展知识面、知识深度和知识广度，掌握各种类型开源项目从宏观架构到核心实现细节的全链路情况，能够比较不同项目的技术特点、业务特点、关键设计取舍和实现方式。

## 期望最终能够做到

- 从仓库结构、入口、配置和依赖快速建立项目心智模型；
- 沿一个真实功能从入口追踪到核心逻辑、数据访问、外部系统和输出；
- 解释项目的技术栈、业务边界、主要设计决策、异常路径和测试证据；
- 对不同类别项目进行横向比较，识别共性模式、差异化方案和适用场景；
- 在源码、测试和可靠文档之间交叉验证结论，并定位到可复查的文件与符号。

## 范围与范围外

范围内：`open-ai-agent/sub2api-plus` 当前 checkout 的项目级总览、Go 后端、前端、部署与配置、Provider/协议适配、认证/计费/配额、账户调度与故障转移、管理端功能、数据流、边界条件、测试和发布运维链路。

范围外：当前 change 不学习其他 submodule；不替用户修改或发布 `sub2api-plus` 代码；不写入未经验证的性能、业务效果或安全结论；不把全部源码压缩成不可复习的长文。课程按“项目地图 → 模块与入口 → 代表性请求链路 → 核心实现细节 → 测试/部署/安全边界”拆分为可在 20–30 分钟内完成的短课。

## 可用时间与教学偏好

- 交互语言：简体中文。
- 教学表达：通俗短句；先图后文；术语先解释后命名。
- 图解：仅纯文本 ASCII。
- 单次节奏：每次 20–30 分钟。
- 复习：首次保持测验至少间隔 24 小时，随后按 7、30、90 天复习。

## 来源范围

- 项目事实：各 submodule 当前 checkout 的源码、README、配置、测试、构建脚本和 git 历史；
- 权威外部来源：项目官方仓库、官方文档和发布说明，仅在使用时验证；
- 横向比较：以已验证项目事实为依据，不把类比或模型总结当作事实。

## 安全与副作用限制

学习过程只读项目源码和可靠来源，教学与学习状态写入本仓库 Learning state 和 `teach/` 工作区；不修改、提交、推送、部署或发布任何 submodule，也不写入敏感信息。
