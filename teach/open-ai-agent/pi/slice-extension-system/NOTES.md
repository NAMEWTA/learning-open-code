# 教学笔记：扩展系统深度实现

## 课程体系说明

本主题包含 5 节课，分两个层级：

- **0001（L2 流程总览）**：全链路时序图 + 发现规则 + 事件分发总览
- **0002-0005（L3 深度实现）**：逐层剖析架构设计原理

建议按编号顺序学习。L2 课建立全局认知，L3 课解答"为什么这样设计"。

## 用户偏好

- 关注点：扩展系统的设计原理和架构灵活性，而非 API 使用教程
- 学习目标：理解实现逻辑后能独立开发 Pi 扩展
- 语言：简体中文
