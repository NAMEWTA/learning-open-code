# 教学笔记

## 用户偏好
- 用户已有 TypeScript/Node.js 编程基础
- 关注实战可用的代码示例，不喜欢纯理论
- 想确认 pi-tui 能否脱离 Pi 生态独立使用（答案：可以，它是零依赖 Pi 其他包的独立 npm 包）

## 前置知识假设
- 用户已了解终端 ANSI 转义序列的基本概念（或可从第 1 课中快速补充）
- 用户知道 Node.js 的 stdin/stdout 流模型
- 用户不要求了解 Pi monorepo 的其他包

## 与已有主题的关系
- `module-tui/`：L1 模块总览——架构理论，本主题是其 L3 实战延伸
- `slice-tui-render-cycle/`：L2 渲染循环追踪——内部实现细节，本主题侧重「怎么用」而非「内部怎么实现」
- 本主题与上述两个主题互补，可独立学习
