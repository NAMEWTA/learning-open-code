0003 — pi-tui 嵌入使用实战

层级：L3 微观 API 预计时长：15 分钟 学习目标：1 个

学习目标：能独立安装 pi-tui、创建最小 TUI 应用、使用内置组件、编写自定义 Component、使用 Overlay 弹窗。

1. 最小可运行示例

安装与三步启动：

npm install @earendil-works/pi-tui
import { TUI, Text, ProcessTerminal, matchesKey } from "@earendil-works/pi-tui";

// ① 创建终端传输层
const terminal = new ProcessTerminal();

// ② 创建 TUI 实例
const tui = new TUI(terminal);

// ③ 添加组件
tui.addChild(new Text("你好，pi-tui！"));

// ④ 拦截 Ctrl+C（raw mode 下不会自动 SIGINT）
tui.addInputListener((data) => {
  if (matchesKey(data, "ctrl+c")) {
    tui.stop();
    process.exit(0);
  }
});

// ⑤ 启动渲染循环
tui.start();

运行这段代码，终端进入 raw mode，显示 "你好，pi-tui！"，按 Ctrl+C 退出。这就是 pi-tui 的最小骨架——Terminal + TUI + Component + InputListener。

2. 内置组件速览

pi-tui 提供了 13 个内置组件，以下是嵌入式开发最常用的 4 个：

组件用途关键方法
Text 显示多行文本，自动换行 setText(str)、setCustomBgFn(fn)
Input 单行文本输入 getValue()、setValue(str)、onSubmit
Editor 多行文本编辑器 getText()、setText(str)、onSubmit
Box 容器，加内边距和背景色 addChild(c)、setBgFn(fn) 
// 组合使用示例
import { Box, Input, Text } from "@earendil-works/pi-tui";

const box = new Box(2, 1, (s) => `\x1b[44m${s}\x1b[0m`); // 蓝底
box.addChild(new Text("请输入你的名字："));
const input = new Input();
input.onSubmit = (name) => {
  box.addChild(new Text(`你好，${name}！`));
};
box.addChild(input);
tui.addChild(box);
tui.setFocus(input);

3. 编写自定义 Component

实现 Component 接口只需三个方法。以下是一个带缓存的进度条组件：

import type { Component } from "@earendil-works/pi-tui";
import { visibleWidth, truncateToWidth } from "@earendil-works/pi-tui";

class ProgressBar implements Component {
  private percent = 0;
  private cachedPercent = -1;
  private cachedLines: string[] = [];

  setPercent(p: number) { this.percent = Math.max(0, Math.min(100, p)); }

  invalidate() { this.cachedPercent = -1; }

  render(width: number): string[] {
    if (this.percent === this.cachedPercent) return this.cachedLines;

    const barWidth = Math.max(10, width - 12);
    const filled = Math.round((this.percent / 100) * barWidth);
    const bar = "█".repeat(filled) + "░".repeat(barWidth - filled);
    let line = ` [${bar}] ${this.percent}%`;

    // 必须截断到 width，否则 TUI 崩溃
    if (visibleWidth(line) > width) {
      line = truncateToWidth(line, width);
    }
    line = line.padEnd(width);

    this.cachedPercent = this.percent;
    this.cachedLines = [line];
    return this.cachedLines;
  }
}

三条铁律：

  1. render() 返回的每一行必须 visibleWidth ≤ width
  2. 内部应做缓存：状态未变时返回缓存数组，避免无谓的逐行比对开销
  3. 调用 invalidate() 清除缓存，通常由外部在主题或数据变更时触发

4. Overlay 弹窗实战

Overlay 是 pi-tui 的模态层系统——在现有内容之上叠加组件，不替换底层内容：

import { Text, Box } from "@earendil-works/pi-tui";

function showConfirmDialog(tui: TUI, message: string) {
  const dialog = new Box(2, 1);
  dialog.addChild(new Text(message));
  dialog.addChild(new Text("按 Enter 确认，Esc 取消"));

  const handle = tui.showOverlay(dialog, {
    anchor: "center",
    width: "60%",
    maxHeight: "30%",
  });

  // overlay 自动获得焦点，按 Esc 关闭
  return handle;
}

Overlay 关键配置：anchor（9 种锚点位置）、width/height（支持百分比如 "50%"）、nonCapturing（设为 true 时不抢焦点）、visible()（根据终端尺寸动态显示/隐藏）。

⚠️ 注意：Overlay 的 hide() 是永久移除，setHidden(true/false) 是临时隐藏/显示。如果需要可恢复的弹窗，用 setHidden() + focus()。

✍️ 动手练习

编写一个 Clock 组件：

  • 实现 Component 接口
  • render(width) 返回一行，显示当前时间（如 "🕐 15:04:05"）
  • 使用 setInterval 每秒更新并调用 tui.requestRender()
  • 确保行宽不超过 width，做好缓存

class Clock implements Component {
  private time = "";
  private cachedTime = "";
  private cachedLines: string[] = [];

  constructor(private tui: TUI) {
    setInterval(() => {
      this.time = new Date().toLocaleTimeString("zh-CN", { hour12: false });
      this.tui.requestRender();
    }, 1000);
  }

  invalidate() { this.cachedTime = ""; }

  render(width: number): string[] {
    if (this.time === this.cachedTime) return this.cachedLines;
    let line = `🕐 ${this.time}`;
    if (visibleWidth(line) > width) line = truncateToWidth(line, width);
    line = line.padEnd(width);
    this.cachedTime = this.time;
    this.cachedLines = [line];
    return this.cachedLines;
  }
}
