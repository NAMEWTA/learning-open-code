第三课：个人模式——构建你的知识库

学习目标：理解个人模式的价值，学会初始化个人知识库并接入外部数据源。

1. 个人模式概述与初始化

代码模式是为项目生成文档。个人模式则是为你自己构建知识库——把你的 Gmail、Notion、X/Twitter 书签、浏览的 Hacker News 等来源的信息汇聚到一个 AI 可检索的本地 Wiki 中。

🎯 适用场景：
  • 每天阅读大量技术文章，想自动整理知识体系
  • 把邮件中的重要决策归档到可检索的知识库
  • 将多个信息源（Twitter 书签、Hacker News 收藏）聚合到一处

初始化个人知识库

openwiki personal --init

首次运行时会引导你：

  1. 选择 AI 提供商和模型（同代码模式）
  2. 选择 Wiki 模板 — 预设的知识库结构模板
  3. 配置数据源连接器 — 选择你想接入的信息来源
  4. 保存每个源的摄入说明和更新计划

个人知识库存储在 ~/.openwiki/wiki/ 目录，全局指令文件在 ~/.openwiki/INSTRUCTIONS.md。

2. 连接器认证与数据摄入

要接入外部数据源，需要先完成 OAuth 认证：

连接器认证命令需要提前准备
Slackopenwiki auth slackSlack App Client ID/Secret + ngrok
Gmailopenwiki auth gmailGoogle OAuth Client ID/Secret
X/Twitteropenwiki auth xX API Client ID/Secret
Notionopenwiki auth notion动态注册，无需手动配置

认证流程自动打开浏览器完成 OAuth 登录，凭证安全存储在 ~/.openwiki/.env。

🔐 Slack 特殊需求： Slack OAuth 需要 HTTPS 回调 URL。先运行 openwiki ngrok start 启动隧道，然后用打印的回调 URL 注册 Slack App。

摄入数据：ingest

认证完成后，将数据摄入到个人知识库：

openwiki ingest all                # 摄入所有已配置的来源
openwiki ingest gmail              # 仅摄入 Gmail
openwiki ingest web-search        # 运行所有 Web Search 实例
openwiki ingest web-search-2       # 运行指定实例
openwiki ingest all --print        # 运行后输出并退出

摄入流程分两步：

  1. 写入原始数据 → ~/.openwiki/connectors/<connector>/raw/
  2. Agent 合成 → 从原始数据生成 Wiki 页面 → ~/.openwiki/wiki/

定时自动摄入（macOS）

macOS 上可以用 cron 命令管理 LaunchAgent 定时任务：

openwiki cron list                  # 查看所有定时任务
openwiki cron pause web-search     # 暂停 Web Search
openwiki cron resume web-search    # 恢复
openwiki cron delete web-search    # 删除

定时任务日志在 ~/.openwiki/logs/。

3. 练习：搭建你的个人知识库

📝 动手练习

  1. 运行 openwiki personal --init 初始化个人知识库
  2. 在引导过程中配置至少一个数据源（如 Web Search）
  3. 运行 openwiki ingest web-search 摄入一次
  4. 查看 ~/.openwiki/wiki/ 目录结构

思考题： 代码模式和个人模式共享同一个 Agent 引擎，它们的核心区别是什么？

提示：区别在于数据源（本地仓库 vs 外部连接器）和输出位置（项目目录 vs 家目录）。

回顾要点

  • 个人模式将多个外部数据源汇聚到 ~/.openwiki/wiki/
  • 先 auth 认证连接器，再 ingest 摄入数据
  • Slack 认证需要 ngrok HTTPS 隧道
  • macOS 支持 LaunchAgent 定时自动摄入
