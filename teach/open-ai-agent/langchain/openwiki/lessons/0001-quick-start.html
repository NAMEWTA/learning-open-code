第一课：首次运行与初始化

学习目标：在 15 分钟内完成 OpenWiki 的首次初始化，理解两种运行模式的基本概念。

1. 两种模式与首次运行

在动手之前，先理解 OpenWiki 的两种运行模式：

  • 代码模式（默认）：openwiki --init 为当前代码仓库生成文档，输出到仓库下的 openwiki/ 目录
  • 个人模式：openwiki personal --init 构建个人知识库，数据存储在 ~/.openwiki/wiki/

它们的核心引擎相同，区别在于数据源和输出位置。本课先聚焦代码模式。

首次运行：openwiki --init

确保你已在目标仓库目录下（OpenWiki 会分析当前目录的代码）：

cd /path/to/your/project
openwiki --init

首次运行会触发交互式引导，你需要依次完成：

  1. 选择 AI 提供商 — 默认是 OpenAI。你可以选择 Anthropic、Gemini、OpenRouter 等 12 个提供商之一。
  2. 输入 API Key — 根据所选提供商，粘贴对应的 API Key。输入时会被掩码保护。
  3. 选择模型 — 例如 gpt-5.5 或 gemini-3.5-flash。
  4. （可选）配置 LangSmith API Key 用于追踪。
📌 配置存储： 所有凭证保存在 ~/.openwiki/.env，后续运行无需重复配置。

2. 初始化后的产物与交互使用

openwiki --init 完成后，你的仓库会新增/修改以下内容：

  • openwiki/ 目录 — 核心文档输出，包含架构概览、工作流、领域概念等页面
  • AGENTS.md / CLAUDE.md — 根目录的 Agent 指令文件，OpenWiki 会维护其中的 <!-- OPENWIKI:START -->...<!-- OPENWIKI:END --> 区块
  • .github/workflows/openwiki-update.yml — GitHub Actions 定时更新工作流
  • openwiki/INSTRUCTIONS.md — 你可编辑的用户指令文件，告诉 OpenWiki 文档的范围和重点
💡 试运行： 如果只想看效果而不实际修改仓库，可以先用 openwiki --dry-run 预览。

交互式聊天

不带任何参数直接运行 openwiki，会进入交互式聊天模式。你可以：

  • 发送自然语言指令，例如 "请为这个仓库写一份 API 概览"
  • 连续对话，OpenWiki Agent 会记住上下文
  • 使用 /api-key 更新 API Key，/langsmith-key 更新 LangSmith 凭证
openwiki "请为这个仓库生成文档，重点关注 API 路由"

3. 练习：你的第一次 OpenWiki 运行

📝 动手练习

找一个你熟悉的代码仓库（可以是任何项目），执行以下操作：

  1. 进入仓库目录：cd /path/to/your-repo
  2. 运行：openwiki --init
  3. 按照提示选择一个提供商（如果不想消耗配额，可选择结束后退出）
  4. 查看生成的 openwiki/ 目录结构

思考题： OpenWiki 为什么要在根目录写入 AGENTS.md 和 CLAUDE.md？这对 AI 编码助手有什么好处？

提示：答案在本课第 2 节中。

4. 回顾要点

  • OpenWiki 有代码模式和个人模式两种运行方式
  • openwiki --init 是首次初始化的入口，会引导配置提供商和 API Key
  • 初始化后生成 openwiki/ 文档、Agent 指令文件和 CI 工作流
  • 纯参数 openwiki 进入交互式聊天
