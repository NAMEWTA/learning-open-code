概览

OpenWiki 是一个由 LangChain 开发的 CLI 工具，使用 AI Agent 自动为代码仓库生成并维护文档（代码模式），或为用户构建个人知识库（个人模式）。

💡 核心思路： OpenWiki 使用 DeepAgents 框架运行一个文档生成 Agent，分析你的代码仓库或配置的数据源，生成结构化的 Wiki 文档。

两种运行模式

模式命令输出目录用途
代码模式 openwiki (默认) 仓库下的 openwiki/ 为当前代码仓库自动生成文档
个人模式 openwiki personal ~/.openwiki/wiki/ 构建个人知识库，可接入 Gmail、Notion 等数据源

命令大全

命令说明
openwiki进入当前仓库的交互式代码聊天
openwiki code显式指定代码模式
openwiki personal进入个人知识库模式
openwiki --init初始化文档（默认代码模式）
openwiki --update更新现有文档
openwiki -p "..."单次运行，打印结果后退出
openwiki "消息"带初始消息启动交互会话
openwiki --modelId <id>指定模型 ID
openwiki auth <provider>认证连接器提供商
openwiki auth configure <provider>重新生成连接器配置
openwiki auth tools <provider>列出可用的 MCP 工具
openwiki ingest <target>运行数据摄入与 wiki 更新
openwiki cron list查看定时任务状态
openwiki cron pause <source|all>暂停定时任务
openwiki cron resume <source|all>恢复定时任务
openwiki cron delete <source|all>删除定时任务
openwiki ngrok start [url]启动 ngrok 隧道（Slack OAuth 用）
openwiki --help显示帮助信息

常用选项

选项说明
--init首次生成文档
--update更新已有文档
--mode <personal|code>运行模式
-p, --print单次运行后退出
--modelId <id>指定模型
--dry-run试运行（不实际执行）

初始化与更新

首次初始化（代码模式）

openwiki --init

这会：

  1. 提示你配置 AI 提供商（默认 OpenAI）、API Key 和模型
  2. 在仓库根目录创建 openwiki/ 目录
  3. 生成初始文档：架构概览、工作流、领域概念等
  4. 在仓库根目录写入/更新 AGENTS.md 和 CLAUDE.md
  5. 创建 GitHub Actions 工作流 .github/workflows/openwiki-update.yml

更新文档

openwiki --update

增量更新已有的 openwiki/ 文档。支持带额外提示：

openwiki --update "请先记录 API 路由"

个人模式初始化

openwiki personal --init

首次运行会引导配置数据源连接器（Git 仓库、Gmail、Notion、X/Twitter、Web Search、Hacker News）。

认证与连接器（个人模式）

OpenWiki 支持多种数据源连接器，需要先进行 OAuth 认证：

连接器认证命令说明
Slackopenwiki auth slack需要 ngrok 隧道接收 OAuth 回调
Gmailopenwiki auth gmail需要 Google OAuth 客户端凭证
X/Twitteropenwiki auth xOAuth 2.0 PKCE 流程
Notionopenwiki auth notion动态客户端注册 MCP

认证后，凭证会安全存储在 ~/.openwiki/.env 中。

数据摄入

配置好连接器后，使用 ingest 命令将外部数据摄入到个人 wiki：

命令用途
openwiki ingest all运行所有已配置连接器的摄入
openwiki ingest web-search运行所有 Web Search 实例
openwiki ingest web-search-2运行指定实例（可配置多个同名连接器）
openwiki ingest all --scheduled仅运行已设定计划的连接器
openwiki ingest all --print运行后输出结果并退出

定时任务（macOS）

macOS 上可使用 cron 命令管理 LaunchAgent 定时任务：

命令说明
openwiki cron list列出所有保存的定时任务及 launchd 状态
openwiki cron pause web-search暂停某连接器的定时任务
openwiki cron resume web-search恢复定时任务
openwiki cron delete web-search删除定时任务

定时任务日志位于 ~/.openwiki/logs/ 目录。

CI/CD 集成

OpenWiki 提供三个平台的 CI 模板：

平台配置文件
GitHub Actionsexamples/openwiki-update.yml → 复制到 .github/workflows/
GitLab CIexamples/openwiki-update.gitlab-ci.yml → 复制到 .gitlab-ci.yml
Bitbucket Pipelinesexamples/openwiki-update.bitbucket-pipelines.yml

GitHub Actions 工作流使用 openwiki code --update --print 定期运行，并通过 peter-evans/create-pull-request 提交 PR。

💡 CI 提示： CI 中无需先运行 --init，--update 会在文档不存在时自动创建。
